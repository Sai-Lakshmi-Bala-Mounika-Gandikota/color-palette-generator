# 🎨 Color Palette Generator

A **simple and responsive Color Palette Generator** built using **HTML**, **CSS**, and **JavaScript** for **Hacktoberfest 2025**.  
This project helps users quickly generate, explore, and copy beautiful color palettes for their creative designs.

---

## ✨ Features

- 🎲 Generate random color palettes instantly  
- 📋 Copy HEX color codes with one click  
- ⚡ Lightweight and fast — fully client-side  
- 🧠 Built purely with HTML, CSS, and JavaScript  

---

| Layer | Technologies |
|-------|---------------|
| **Frontend** | HTML5, CSS3, JavaScript (ES6) |
